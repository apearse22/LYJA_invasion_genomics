# Analysis of <i>Lygodium japonicum</i> sequencing data 

## Nuclear Reference 

Low-coverage whole genome shotgun sequencing data (~7x coverage) was downloaded from NCBI (SRA accession SRS3260912). These data were generated by the 10,000 Plant Genomes Project (10KP; Cheng et al. 2018). We used SOAPdenovo to assemble a nuclear reference. Plastid contigs were removed from the assembly by using BLASTn against the <i>Lygodium japonicum</i> reference plastome (NCBI Accession NC022136) and removing any significant hits. Given the high number of contigs, we stiched contigs together using a custom python script `stitch.py`. 

```
SOAPdenovo-63mer all -s soap_config.txt -K 63 -R -p 64 -o LYJA_v0.1 1>asm.log 2>asm.err

makeblastdb -in NC022136.fasta -dbtype nucl

blastn -query LYJA_v0.1.scafSeq.fasta -db NC022136.fasta -evalue 1e-5 -outfmt 6

cut -f1 blast.out | uniq > contig-plastid_blast-hits.txt

seqkit grep -v contig-plastid_blast-hits.txt LYJA_v0.1.scafSeq.fasta > LYJA_v0.1.scafSeq.noCP.fasta

python stitch.py 
```

## Read Mapping 

Raw whole-genome skimming sequence data generated by Markley et al. (2024) were accessed from NCBI BioProject PRJNA1114707. Low-quality reads and adapters were removed with TrimGalore, and trimmed reads were mapped to the stiched nuclear reference with bwa. PCR and optical duplicates were marked with picard.


## SNP Calling 

We used the GATK Best Practices pipeline to genotype each sample. First, we generated preliminary variant calls with HaplotypeCaller, then imported each of these into a GenomicsDB object and did joint-genotyping on this database. We specified a ploidy of 4 for all steps. 

```
# Create a sequence dictionary for the reference 
picard CreateSequenceDictionary R=LYJA.stitched_reference.fasta O=LYJA.stitched_reference

# Call variants for each sample 
gatk HaplotypeCaller -R Lygodium_japonicum_LYJA.fa -I "$sample".markedDups.sortedRG.bqsr.bam -ploidy 4 -O "$sample".g.vcf.gz -ERC GCVF

# Combine all gvcf files: 
gatk GenomicsDBImport --java-options "-Xmx164g -Xms96g" --genomicsdb-workspace-path parallelDB.superContigs --batch-size 10 -L LYJA.stitched_reference.intervals --sample-name-map samples 

# Join genotyping 
gatk GenotypeGVCFs -R LYJA.stitched_reference.fasta -V gendb://parallelDB.superContigs -O LYJA.superContigs.calledGTs.vcf.gz --sample-ploidy 4
```
